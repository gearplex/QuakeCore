QuakeCore result import schema

Minimum keys populate the published EDP dashboard. Optional arrays unlock story shear and time-history views in future runs.

No silent substitutions: the current benchmark still lacks the measured DT1 shake-table acceleration file locally. Importing a QuakeCore result does not upgrade the benchmark to “strict parity” unless the model and input-motion prerequisites are satisfied.
Optional result fields supported by this dashboard:
  • peak_story_shear_kip: [S1,S2,S3]
  • peak_floor_acceleration_g: [F1,F2,Roof]
  • time_s plus response-history arrays
  • solver, elapsed_s, newton_iterations
  • input_motion_provenance for strict-parity traceability
